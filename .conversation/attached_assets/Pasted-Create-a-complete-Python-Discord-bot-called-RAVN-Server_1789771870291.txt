Create a complete Python Discord bot called RAVN Server Manager using discord.py.

The bot is designed for an ARK Survival Ascended PvP community and must be able to automatically build and manage a complete Discord server.

CORE SETUP SYSTEM

Create an administrator-only command:

/setup-server

When run, it should create the complete server structure automatically.

Before creating anything, check whether roles, categories and channels already exist so the command does not create unnecessary duplicates.

PERMISSIONS

Configure permissions properly.

Everyone/New Member should only have access to public information and community areas.

Member should have access to normal community, PvP, recruitment, breeding, trading and ARK channels.

Tribe roles should have access to relevant tribe areas.

Recruiters should be able to manage recruitment channels.

Moderators and administrators should have access to moderation and staff channels.

Management roles should have access to management channels.

Owner should have full access.

Make staff, management and ticket channels private.

Do not give @everyone administrator permissions.

CONFIGURATION

Use environment variables for sensitive information.

The Discord token must be loaded using:

os.getenv("DISCORD_TOKEN")

Never hard-code the bot token.

Create a clean configuration system so server IDs, role names and channel names can be changed easily.

CODE QUALITY

Use Python 3 and discord.py.

Use slash commands.

Use proper error handling.

Use logging.

Use asynchronous functions correctly.

Prevent duplicate setup objects.

Check that the user has the required permissions before administrative commands.
